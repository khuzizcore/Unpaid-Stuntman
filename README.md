🎮 Unpaid-Stuntman

📌 About the Game

Unpaid-Stuntman is a 2D survival game developed collaboratively by Tasnima Anees and Khuzaima using the Godot Game Engine.

🕹️ Gameplay

- Avoid incoming barrels to stay alive.
- The character has 3 lives.
- Each collision puts the character's survival at risk.
- The goal is to survive by avoiding obstacles.

🛠️ Technologies Used

- Game Engine: Godot
- Programming Language: GDScript
